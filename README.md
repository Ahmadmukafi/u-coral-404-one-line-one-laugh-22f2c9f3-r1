Entry for the make.fun bounty **One Line, One Laugh** (u-coral-404-one-line-one-laugh-22f2c9f3).

The program writes a single funny line to `/output/entry.txt`:

> "I have a photographic memory. Unfortunately, the photo is of the wrong meeting."

The joke turns on "photographic memory": the memory is perfect, but the photo it kept is of the wrong meeting.
